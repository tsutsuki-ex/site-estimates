## 2. 推定システム構成

上記のページ構造から、このサイトを裏側で動かすために必要な機能モジュールを逆引きしました。予約・スケジュール管理を中核に、集客用のコラムCMSと検索・ランキングが接続する構成です。

**フロントエンド層**
- 公開サイト（Web / SP）— トップ・検索・セラピスト詳細・予約・コラムのSSR/SSGレンダリング、SEOメタ管理
- 管理画面（バックオフィス）— セラピスト・予約・記事・口コミ・求人の運用管理UI

**アプリケーション層 — 機能モジュール**

| # | モジュール | 説明 |
|---|---|---|
| ① | セラピスト管理 | プロフィール・写メ日記（画像）・稼働ステータスのCRUD |
| ② | 予約・スケジュール | 空き枠カレンダー、コース/時間選択、予約確定フロー |
| ③ | 検索・絞り込み | エリア×条件のファセット検索（19パターン相当） |
| ④ | ランキング集計 | 指名・口コミ実績のバッチ集計（日次/週次/月次） |
| ⑤ | 口コミ・レビュー | 投稿・承認モデレーション、セラピスト別集計 |
| ⑥ | コラムCMS | 記事・カテゴリ（6）・著者・関連記事、全46ページ |
| ⑦ | 紹介・特典 | 紹介コード発行、割引適用のトラッキング |
| ⑧ | 採用エントリー | 求人・モニター応募フォーム、通知連携 |
| ⑨ | 外部連携 | LINE公式アカウント（24時間受付）、アクセス解析 |

**データ・インフラ層**
- RDB — セラピスト・予約・口コミ・記事などのマスタデータ
- 検索インデックス / キャッシュ — エリア検索の高速化、ランキング結果キャッシュ
- 画像/CDN — 写メ日記・コラム記事画像の配信最適化

## 4. 前提条件・スコープ外

### 見積もりの前提
- URL・タイトル・見出し構造から機能を逆引きした概算であり、実際の内部仕様（決済有無、承認フロー、外部システム連携の詳細等）は未確認です。
- セラピスト・記事・エリアの件数は今回クロールした範囲（セラピスト3名、記事33本）を基準としており、実件数が増えてもテンプレート単価には影響しません。
- チーム体制はPM1名・デザイナー1名・フロントエンド2名・バックエンド2名・QA1名（計7名）を想定。

### スコープ外（別途見積）
- オンライン決済機能（本業態では来店時現金決済が一般的なため未算入）
- 写真・記事などのコンテンツ制作費（撮影・執筆・監修）
- 広告運用・集客施策、既存データの移行作業
- 公開後の月次保守・運用（上表の参考値を目安に別途契約）
